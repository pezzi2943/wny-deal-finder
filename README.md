# WNY Rental Deal Finder

Daily-scored for-sale single-family and 2–4 unit listings ($40k–$500k) across Western New York, presented by Paul Pezzimenti, Pezzimenti Realty / Howard Hanna Professionals, Olean, NY (716-378-7039, paul@paulpezzimenti.com).

- `index.html`: the sortable, filterable deals page (served by GitHub Pages)
- `assets/`: Howard Hanna Professionals logos
- `data/deals_web.json`: today's scored listings, refreshed daily

All figures are automated estimates for informational purposes only, not financial, legal or investment advice or an appraisal. Verify independently.
